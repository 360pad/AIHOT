# Tender Radar V0.1 架构分析

## 1. 项目目标

基于 AIHOT 框架，将领域从 AI 热点扩展为企业招投标/标前公示情报雷达。

核心原则：最大化复用 AIHOT，不重写核心流程。

2026-10-11 补充：企业能力、关键词与大模型的后续业务设计见
[企业业务匹配设计](TENDER_RADAR_BUSINESS_MATCHING_DESIGN.md)。该稿将交付能力与行业场景分开，并列出必要的后端契约改动；仍保留采集、预筛、双评分、聚类、热度和日报流程。本分支已完成第一轮实现，待数据库、模型调用和真实样本验收。

## 2. AIHOT 可复用能力

AIHOT 已具备：

- 信息源管理
- 信息采集流程
- 内容去重
- LLM 预筛
- 多次评分
- 中文标题与摘要生成
- 事件聚类
- 热点计算
- 日报生成

这些能力直接对应招投标情报流程。

## 3. Tender Radar 数据流

```
招标/标前信息源
        ↓
采集
        ↓
去重
        ↓
LLM业务相关性判断
        ↓
项目事件聚类
        ↓
趋势热度计算
        ↓
企业情报日报
```

## 4. 第一版改造原则

不修改 AIHOT 核心引擎，优先通过 industry 扩展。

新增内容：

- tender sources
- 企业业务分类
- 招投标分析 Prompt
- 招投标日报模板

## 5. V0.1 不包含

- CRM
- 销售流程管理
- 自动投标
- 客户画像
- 复杂知识图谱平台
